# Barclays

```
index.html          markup only (no inline styles), BEM class names
scss/main.scss      single master stylesheet with tokens, components, and all sections
css/main.css        compiled output (npx sass scss/main.scss css/main.css)
js/main.js          interactions, tabs, and Swiper sliders
assets/images/      local image assets (img-01.jpg ... img-20.jpg)
```

## Images
All image assets (`img-01.jpg` through `img-20.jpg`) are saved locally in `assets/images/` and served directly by `index.html`.
